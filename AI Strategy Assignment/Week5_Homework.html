Question 1

Combining Text Embeddings with Structured Features

Scenario

You are building a fraud-classification model. Each transaction contains text that is converted into a 768-dimensional embedding vector. You also have two structured variables — for example, transaction amount and account age — that you believe contain important predictive information.

768dims from the text embedding
2structured variables (amount, account age)
770?the simple concatenation
Question

How would you combine the two structured variables with the 768-dimensional text representation so the model can effectively learn the contribution of both types of information?

  1. Would you simply concatenate the two variables to the embedding and create a 770-dimensional input? Why might that work, and what issues would you still need to consider?
  2. Would you normalize or transform the structured variables before combining them with the text representation?
  3. Would you process text and structured data through separate branches and fuse the representations later? What advantage might this provide?
  4. Does having 768 text dimensions and only 2 structured variables automatically mean the structured variables will have less influence? Explain why or why not.
Deliverable Compare at least two possible architectures and recommend one. A simple diagram is encouraged.

Question 2

What Changes When a Model Learns a New Skill?

Scenario

Suppose a pretrained model is adapted to perform a new task or acquire a new domain-specific skill.

Question

Does learning the new skill necessarily mean that the model becomes larger? Distinguish between changing the values of existing parameters and adding new trainable parameters or components to the architecture.

  1. What is a model parameter, and what happens to parameter values during training?
  2. Can the same model architecture behave differently after training even when the number of parameters stays the same?
  3. Use at least two techniques discussed in class — Continued Pretraining (CPT), Instruction Fine-Tuning (IFT), Classification Fine-Tuning (CFT), or DPO — to support your explanation.
  4. Identify at least one case from today's material where adapting the model may introduce an additional set of parameters rather than only changing existing values.
Deliverable Answer conceptually; no discussion of LoRA, QLoRA, or other PEFT methods is required for this homework.

Question 3 · Design challenge

Design an Offline AI Maintenance Assistant

Scenario

An airline maintenance technician is working at an offsite location with an iPad and unreliable or unavailable Internet access. The technician needs to troubleshoot repairs by asking natural-language questions. The airline has approximately 10 GB of maintenance manuals, troubleshooting procedures, and related technical documentation.

iPadlimited memory and compute
Offlineno API calls at inference
10 GBmanuals and procedures
Changing docsprocedures get revised
Deployment constraint Training, indexing, model preparation, and optimization may happen centrally before deployment. At inference time, however, the iPad must operate entirely offline and cannot make an external API call.
Design challenge

Design a system and justify your choices. Your answer should address only the following four questions:

  1. On the device: What model or models would actually run on the iPad, and how would you make them practical for limited memory and compute?
  2. Where knowledge lives: Where would the knowledge from the 10 GB corpus live: primarily in model weights, in a local retrieval store, or in a combination of both?
  3. Techniques: Which techniques would you use — such as CPT, IFT, CFT, RAG, model compression/quantization, or a smaller language model — and what specific role would each selected technique play?
  4. Keeping it reliable: How would you keep the system reliable when maintenance manuals or procedures change over time?
CPTIFTCFT RAG / local retrievalCompression / quantizationSmaller language model
Deliverable One architecture diagram plus a maximum one-page justification. Do not simply say "use RAG" or "fine-tune a model." Show where the knowledge lives and how a technician's question flows through the system to the final answer.
